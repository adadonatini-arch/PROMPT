# Partita ridotta

Ordini vocali coreografici per corpi e pubblico. Web app installabile (PWA), funziona anche offline.

## Uso
Apri il link della pagina pubblicata. Per installarla: Chrome/Edge → icona "Installa" nella barra; iPhone/iPad → Condividi → "Aggiungi a Home"; Android → menu → "Installa app".

## Audio
Cartella `audio/`: `regole.mp3`, `finale.mp3`, `musica.m4a`. Se un file manca la partita prosegue senza; la musica si può anche caricare dal pulsante CARICA MUSICA.

## Pubblicare su GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → branch `main`, cartella `/ (root)`.
